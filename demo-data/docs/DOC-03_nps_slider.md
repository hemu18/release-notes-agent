# Adding an NPS slider question

Doc ID: DOC-03 · Source: Confluence · Last updated: 2026-11-17 · Audience: all customers

## What's new in 4.12
The survey builder has a new question type: **NPS slider**. Respondents drag a slider from 0 to 10. The layout is designed for phones first and works on desktop.

## Adding the question
1. Open a survey in the survey builder.
2. Click **Add question** > **NPS slider**.
3. Edit the question text and the labels at each end (for example "Not likely" and "Very likely").
4. Preview and publish.

## Reporting
NPS slider answers feed the same NPS score and reports as the existing NPS question. Customers can switch an existing NPS question to the slider without losing past responses.

# Switching review widgets from grid to carousel

Doc ID: DOC-04 · Source: Confluence · Last updated: 2026-11-19 · Audience: all customers

## What changed in 4.12
A new **carousel** layout is available for review widgets. The **grid** layout is deprecated and will be removed at the end of the current quarter (31 December 2026). After that date, grid widgets stop displaying.

## Who needs to act
Any site still using a grid widget must switch before 31 December 2026.

## How to switch
1. Go to Widgets > My widgets and filter by Layout: Grid.
2. Open each widget and choose **Layout: Carousel**.
3. Adjust the number of cards shown and the colours to match your site.
4. Click **Publish**. The embed code does not change, so no website update is needed.

## Known limits
- The carousel shows up to 12 reviews.
- Custom CSS written for the grid layout does not carry over and needs redoing.

# Branded SSO login page – Bluepeak Mortgages

Doc ID: DOC-08 · Source: Google Drive · Last updated: 2026-11-15 · Audience: **Bluepeak Mortgages only — do not share with other customers**

## What we built
Bluepeak's SSO login page now shows the Bluepeak logo and colours, and a "Need help signing in?" link to Bluepeak's IT helpdesk. This was requested by Bluepeak's IT team.

## What Bluepeak users will see
- The Bluepeak logo above the sign-in button.
- Bluepeak's blue colour scheme.
- A helpdesk link that opens Bluepeak's internal IT portal.

## What Bluepeak's admin can change
Admin > Security > SSO > Login page lets the admin replace the logo, change the helpdesk link, or switch back to the standard page.

Bluepeak also uses SAML SSO, so the certificate rotation in DOC-07 applies to them as well.

# Reminder settings for campaigns

Doc ID: DOC-02 · Source: Confluence · Last updated: 2026-11-18 · Audience: all customers

## What changed in 4.12
The default reminder interval is now **5 days** (previously 3 days). Campaigns that already have a custom interval are not affected.

## Who will notice
Any campaign using the default setting now sends fewer reminders. Response rates may dip slightly in the first weeks; customers who had complained about too many reminders will see fewer.

## Keeping the old interval
1. Open the campaign and go to Settings > Reminders.
2. Choose **Custom interval** and set it to 3 days.
3. Save. The setting applies to reminders scheduled after the save.

## Setting an account-wide default
Admins can set a default for all new campaigns under Admin > Campaign defaults > Reminder interval.
